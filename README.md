# AIツール比較メモ

AIツールの名前・月額料金・用途メモを登録・比較する、HTML・CSS・JavaScript製のアプリです。外部API・ライブラリーは使用していません。初期データは架空のサンプルです。

## 使い方

GitHubの「Code → Download ZIP」でダウンロードし、展開後の `index.html` をブラウザーで開いてください。インストールやビルドは不要です。

## 主な機能

- 初期データ表示、追加・編集・削除、名前・メモの部分一致検索、料金順の並べ替え
- ブラウザー内への保存、初期状態へのリセット、日本語対応のCSV出力
- 必須欄・料金・重複名の検証（0円、空欄メモは登録可能）
- 入力内容をHTMLとして実行しない表示と、CSVの数式対策
- スマートフォン対応と初回操作ガイド（広い画面ではタイトル右側、狭い画面では下に配置）

## 動作確認方法

1. 初期データ3件と初回ガイドが表示されることを確認します。
2. 追加・編集・削除、検索、料金順の並べ替えを試します。空欄・負数・重複名が拒否され、0円が登録できることも確認します。
3. 再読み込み後のデータ保持、リセット、日本語を含むCSV出力を確認します。
4. 画面幅を狭め、ガイドと入力欄が重ならないことを確認します。

本人はPCのChromeとAndroid端末で通常操作・CSV出力・ガイド表示を確認しました。AIによる自動検証では基本機能、ガイドの操作・既読保持、画面幅320〜1440pxの表示を確認しています。本人が最新改修版の全機能を各端末で網羅的に検証したものではありません。

Safari・Firefox、支援技術、大量データ、表計算ソフトでのCSV読込は未確認です。複数タブの同時編集は同期せず、最後の保存が優先されます。保存を禁止した環境ではデータやガイドの既読状態を保持できない場合があります。
