# AIツール比較メモ

HTML・CSS・JavaScriptのみで動く、AIツールの名前・月額料金・用途メモを比較するアプリです。ZIPを展開し、`index.html` をブラウザーで開いてください。ビルド・インストール・外部API・CDNは不要です。合成サンプルデータだけを使用しています。

## 今回の変更

### ガイドのレスポンシブ配置

タイトル群とガイドを、折り返し可能なFlexboxの同じヘッダー内に配置しました。タイトル群の目安幅320px、ガイドの目安幅380px、間隔24pxが収まる利用可能幅では横並びになり、収まらないとガイドがタイトルの下へ自然に折り返します。端末名・User-Agent・画面の縦横では判定しません。小画面では各要素も利用可能幅まで縮み、長い文を折り返します。

専用Chromeで320・390・768・1024・1440pxの各幅について、1段目と2段目の計10条件を確認しました。今回のUIでは320・390・768pxはタイトル下、1024・1440pxは右側に配置されます。全条件で横スクロール、タイトルやフォームとの重なり、文字のはみ出しがないことを検証しました。ガイドの閉じる・次へ・既読保持など12グループと既存機能14グループも通過しています。これは自動ブラウザー検証の結果であり、本人による実機操作確認とは区別しています。

### 維持した初回ガイド

- 説明文を指定どおり「AIツール月額料金のデータベースメモ♪」に変更。
- 初回だけ、入力方法と検索・並べ替えを説明する2段階の吹き出しガイドを表示。「次へ」で進み、「閉じる」で途中スキップまたは完了できます。ガイドのボタンにフォーカスがあるときはEscapeでも閉じられます。
- ガイドは入力欄を覆わない通常レイアウト内に配置。表示中でもフォームを操作できます。キーボードのフォーカスを閉じ込めません。
- 閉じる・完了の記録は専用キー `nitti.ai-tool-memo.guide.v1` に保存。ツールデータのキー `nitti.ai-tool-memo.v1` とは独立しており、「初期状態に戻す」でも既読は消しません。
- localStorageが使えない場合はsessionStorageへ退避。両方使えなくても例外で停止せず、同じページを開いている間は閉じたガイドを再表示しません。すべての保存機能が禁止された環境でページを再読み込みすると、既読を永続保持できず再表示する場合があります。

## 既存の仕様

- 初期データは `[{"name":"Alpha","monthly":3000,"memo":"文章"},{"name":"Beta","monthly":0,"memo":"調査"},{"name":"Gamma","monthly":5000,"memo":"画像"}]`。各項目には固定IDを付け、新規登録にはUUID等を使用します。
- 表示・追加・編集・削除、名前またはメモの部分一致検索、登録順・月額昇順・降順、localStorage保存、初期データへのリセット、CSVダウンロードに対応。
- 名前・料金は必須。メモは空欄可。名前は前後空白を除去して100文字以内、メモは2,000文字以内。文字数はJavaScriptの文字列長で判定します。
- 料金は0〜999,999,999円の半角整数。0円と先頭の0は有効。空欄、負数、小数、指数、カンマ、全角数字は不可。
- 重複名はNFKC正規化・前後空白除去・英字小文字化して照合。全半角と大小の差は同じ名前と扱い、内部の空白は除去しません。編集中の自身は重複に含めません。検索にも同じ正規化を適用します。
- 編集・削除は表示順に依存せずIDで処理。同額ソートは登録順を維持。編集キャンセルはデータを変えず、削除・リセットには確認を表示します。
- 空配列を保存するため、全件削除後の再読込で初期データは復活しません。壊れた保存データは警告し、元データを自動上書きせず初期データを一時表示。明示的なリセットで復旧します。書込失敗も警告します。
- 入力はtextContent・フォームのvalueで扱い、HTMLとして実行しません。
- CSVは検索・並べ替えによらず全件を登録順で出力。UTF-8 BOM、日本語見出し、CRLF行区切り、全セル引用符、引用符の二重化に対応。セル内の改行・カンマを保持します。先頭の空白・制御文字の後を含む `= + - @`、またはタブ・CR・LFで始まる文字列にはアポストロフィを付け、数式としての解釈を抑制します。この保護はCSV上の値を変えますが、保存データは変えません。
- 保存はブラウザーとオリジン単位。ファイルを別の場所へ移した場合などのlocalStorageの扱いはブラウザーに依存します。複数タブの同時編集は同期せず、最後に保存した内容が優先されます。

## テスト手順

他のデータを使わないテスト用ブラウザープロファイルで確認してください。

1. 初回にガイド1とAlpha・Beta・Gammaが表示され、Betaが0円であることを確認。
2. ガイド表示中に入力・0円追加ができることを確認。「閉じる」でスキップし、再読込で表示されず追加データも残ることを確認。
3. テスト用環境のガイド専用キーをlocalStorageとsessionStorageの両方から削除して再読込。「次へ」で2番目の案内へ進み、閉じて再読込。非表示を確認。初期状態へのリセットでも既読が残ることを確認。
4. ガイドのボタンへTabで移動し、Enterで進む・閉じる操作、Escapeでスキップを確認。次へ進むと閉じるボタン、閉じると名前欄にフォーカスが移ることを確認。
5. 空欄・空白名・空欄料金・負数・小数・指数・範囲外・重複名（例：` ＡＬＰＨＡ `）が拒否され、0円と空欄メモは登録できることを確認。
6. 名前の一部・メモの一部で検索し、料金順に並べ替えて対象を編集・削除。編集キャンセル、削除確認の取消、全件削除後の再読込、リセットを確認。
7. `<img src=x onerror="alert(1)">` 等を入力し、文字として表示され実行されないことを確認。
8. 日本語・カンマ・引用符・改行・数式開始文字を含むデータをCSV出力。検索中も全件を含むこと、BOMと引用符・数式対策を確認。
9. テスト用の保存データに壊れたJSON・重複ID・不正料金を設定し、警告と元データの上書き防止を確認。書込拒否時の警告も確認。
10. 320px・390px幅でガイドの両段階がはみ出さず、入力欄を覆わないことを確認。保存機能をテスト用に無効化し、閉じた後に再表示せず操作を継続できることも確認。
